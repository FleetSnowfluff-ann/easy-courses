debugpy 新架构优势2026.1

🚀 debugpy（Debug Adapter Protocol）

PyCharm 2026.1 将默认调试后端切换为 debugpy，这是 VS Code、PyCharm、Jupyter 等工具通用的行业标准协议（DAP）。优势：① 消除旧版 socket 等待的竞态条件；② 与 Jupyter 单元调试统一；③ 更稳定的 Docker/SSH 远程调试。可在 Settings → Build → Python Debugger 中配置。

第七章

测试与覆盖率

PyCharm 深度集成 pytest / unittest，支持可视化测试运行、覆盖率高亮显示、参数化测试展开，是 Python 测试的最佳 IDE 体验。

编写 pytest 测试

test_calculator.pyimport pytest
from calculator import add, divide

# 基础测试
def test_add_positive():
    assert add(2, 3) == 5

# 参数化测试 - PyCharm 会展开为多个测试节点
@pytest.mark.parametrize("a,b,expected", [
    (1, 2, 3),
    (-1, 1, 0),
    (0, 0, 0),
])
def test_add_parametrized(a, b, expected):
    assert add(a, b) == expected

# 异常测试
def test_divide_by_zero():
    with pytest.raises(ZeroDivisionError):
        divide(10, 0)

运行测试的方式

📊

coverage.py 覆盖率结果（代码行高亮）

当你修改代码时，PyCharm AI 实时预测需要级联修改的位置，内联灰色显示建议。按 Tab 接受当前建议，再按 Tab 跳到下一个建议位置。不是 AI 全盘重写，而是精准的逐步引导，开发者始终保持控制权。典型场景：函数重命名、参数变更、接口修改的连带更新。

④ ACP Registry — AI Agent 应用市场全新

🗂️ 内置 AI 编码 Agent 目录

ACP（Agent Control Protocol）Registry 是一个内置在 IDE 中的 AI 编码 Agent 目录，帮助你发现和集成最新的 AI 工具。随着 AI 编码 Agent 日新月异，ACP Registry 让你在同一个工作流中选择和切换最适合当前任务的 Agent。

⑤ BYOK（Bring Your Own Key）新增

🔑 使用自己的 AI API Key

在 IDE 设置中直接配置来自 OpenAI、Anthropic 或兼容提供商（含本地模型）的 API Key。使用自己的订阅，控制成本，在 PyCharm 内完成所有 AI 辅助开发。

uv 包管理器支持延伸到 SSH 和 Docker 远程开发环境，与本地开发体验统一。
